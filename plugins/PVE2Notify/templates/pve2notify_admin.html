PVE2 Notify State Change Notifications

ℹ️ How notifications work & why

How it works: every check stores a snapshot of all machine states; the next check diffs against it. Differences become events — machine added, removed, started or stopped — and each event is formatted and sent to every enabled provider (Discord, Slack, Mattermost, Telegram).

Why snapshots: only changes generate messages. A quiet cluster sends nothing — when something pings you at 3am, it actually happened.
