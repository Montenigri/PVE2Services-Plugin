PVE2 Proxy Reverse Proxy Manager

ℹ️ How the proxy manager works & why

How it works: for each enabled mapping, one nginx server block is generated (<hostname>.<domain> → ip:port, with optional websocket passthrough, caching and rate limits), then deployed over SSH (key auth, scp + atomic move) and nginx is reloaded.

Why: expose internal services by name without hand-editing server blocks — add a mapping, deploy, done.

Preview shows the exact file content before anything is written. If the reload command fails, the config is already in place and the deploy reports a warning instead of an error.

Safety: the reload command is restricted to known nginx/systemctl commands, and SSH uses key-based auth only.
