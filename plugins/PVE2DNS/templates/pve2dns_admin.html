PVE2 DNS DNS Record Management

ℹ️ How DNS sync works & why

How it works: for every machine you enable, a DNS A record <hostname>.<your domain> → IP is created in Pi-hole or AdGuard Home on the next sync. Disabling a record removes it on the next sync.

Why: your Pi-hole/AdGuard already answers DNS for the whole network — using it as the machine registry gives every VM/LXC a resolvable name without touching /etc/hosts on each client.

IP source: the QEMU guest agent reports running machines' IPs automatically. Machines without the agent (or stopped ones) show an empty IP — fill it in manually before enabling the record.

Idempotent: the domain suffix is appended only once, so web and web.lab.local both end up as web.lab.local.
