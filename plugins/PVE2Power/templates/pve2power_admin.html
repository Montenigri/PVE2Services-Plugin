PVE2 Power Power Scheduler

ℹ️ How the power scheduler works & why

How it works: each machine can have a schedule — on/off windows for weekdays and the weekend, active days, timezone. Every check computes whether each machine should be on right now, reads its current status live from Proxmox (never from the cache, so a machine you toggled manually is respected) and issues a start or stop only when the two disagree.

Why: cut energy waste for machines that are not needed 24/7 — workstations, build rigs, test boxes — without cron scripts on the host.

Safety: only machines with an enabled schedule are ever touched; every action is recorded (last action + timestamp, shown per machine); after acting, the cache is updated so the UI reflects reality immediately; with multiple replicas only the lease holder runs checks, so nothing double-fires.

Note: stop is a graceful ACPI shutdown — the guest OS must handle it (install qemu-guest-agent / enable ACPI).
