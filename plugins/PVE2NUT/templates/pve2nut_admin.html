PVE2 NUT UPS Dashboard

ℹ️ How the UPS dashboard works

Multi-server: configure one or more NUT servers (upsd, default port 3493). Devices sharing the same UPS name across servers are merged into one logical UPS — the first reachable server (config order) serves the data, the others act as standby and are marked on the card.

History: the background poller saves a reading per UPS at every cycle; charts show battery charge, load and voltages over time. Old readings are pruned after the configured retention.

Events & notifications: status transitions (on battery, low battery, back online) and communication loss are recorded and, if enabled in config, delivered through the channels configured in PVE2Notify.

Commands: instant commands (beeper, battery test, shutdown...) are sent via INSTCMD — a NUT user with command rights is usually required in the server config.
